## 第二阶段验收场景（对应自动化测试）

`e2e/online-gomoku.spec.ts › 两台手机联机下完整一局五子棋`，两个**独立浏览器上下文**（独立 localStorage，相当于两台手机）：

| # | 验收项 | 结果 |
| --- | --- | --- |
| 1 | 手机 A 创建房间 | ✅ 生成 4 位吉利房间号（如 8888）与邀请链接 `/r/8888` |
| 2 | 手机 B 通过邀请链接进入 | ✅ 加入页显示“奶奶 邀请你一起玩 五子棋” |
| 3 | 双方准备并开始 | ✅ 未准备时“开始游戏”禁用并提示原因 |
| 4 | 轮流落子、实时同步 | ✅ 对方回合不能落子；快速连点只落一子 |
| 5 | 断线后恢复 | ✅ 断网 → 对方看到“离线/掉线了” → 恢复网络自动回到原座位；页面刷新也能恢复 |
| 6 | 旋转手机不影响对局 | ✅ 竖屏选中落点 → 转横屏 → 选中仍在、连接未断（socket id 不变）→ 直接确认落子 |
| 7 | 正确判断胜负 | ✅ 服务端判定五连，双方显示“你赢了！/奶奶 赢了”，连珠高亮 |
| 8 | 重新开始 | ✅ “再来一局”后先后手交换，显示“第 2 局” |
| 9 | 退出并返回大厅 | ✅ 对局中退出需确认（算认输），对方获胜；房主自动移交 |
| 10 | 房间失效 | ✅ 全员离开后链接显示“没有找到这个房间” |

其他 E2E：电脑（鼠标）与手机（触屏）混合对局 + 切后台返回探活；房间号输错、房间已满、对局中不能加入、误回首页可一键回房间；人机对局；连续旋转 6 次不断线不丢状态。
